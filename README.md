# App-Keufland-Store

Diseñamos un sistema de punto de venta para un tienda en Liepzig, Alemania, llamada Keufland (simulada).

Dentro del programa usamos más de 9 librerías en Python.

## Cómo Usarla

Descargar el código, en caso de errores de debugging, favor de descargar las librerías necesarias para el programa.

Posiblemente necesitas descargar CustomTkinter:
```bash
pip install customtkinter
```
